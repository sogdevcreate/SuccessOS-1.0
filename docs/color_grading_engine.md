# Color Grading Engine

The provider-neutral Color Grading Engine holds per-shot exposure, contrast, white-balance/tint, saturation, highlights/shadows/black-level, look-profile, and shot-matching decisions. Skin-tone protection is enabled by default to preserve photorealistic human skin tones. Grading reads the approved edit and production direction and writes only `StudioProject.color_grade`.

Shot-match plans preserve adjacent-shot exposure, white balance, contrast, saturation, skin-tone, environment-color, lighting, time-of-day, and weather continuity. Color review scores matching, realism, consistency, palette, cinematic quality, scene continuity, and production direction compliance.
